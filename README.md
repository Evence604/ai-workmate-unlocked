# AI WorkMate

Prompt: AI WorkMate
Build a modern, professional AI productivity web application called “AI WorkMate” with three main features:
1. AI Research Assistant
2. Smart Email Generator
3. Meeting Notes Summarizer
⚠️ Important
Do NOT include authentication of any kind.
No Login
No Sign Up
No Registration
No Passwords
No User Accounts
No Authentication pages
No Payment or Subscription system
The application must open directly to the main dashboard and allow users to use all features immediately.
🔎 AI Research Assistant
Allow users to enter a topic or question and generate:
Research summaries
Key findings
Important points
Insights
Recommendations
Suggested research questions
Add Copy, Save, Clear, and New Research buttons.
📧 Smart Email Generator
Allow users to enter the purpose and details of an email and automatically generate a professional email.
Include tone options:
Formal
Friendly
Persuasive
Professional
Apologetic
Include:
AI-generated subject line
Editable email
Copy button
Regenerate button
Clear button
📝 Meeting Notes Summarizer
Allow users to paste or type meeting notes and generate:
Meeting Summary
Key Discussion Points
Decisions
Action Items
Deadlines
Responsible people when mentioned
Include Copy, Save, Clear, and Summarize Again buttons.
🏠 Dashboard
Create an attractive dashboard with three main feature cards:
🔎 Research Assistant
Research and understand topics quickly.
📧 Email Generator
Create professional emails in seconds.
📝 Meeting Summarizer
Turn long meeting notes into clear action points.
Add quick-action buttons for each feature.
🎨 Design
Make the website modern, professional, attractive, and easy to use.
Include:
Modern sidebar navigation
Clean dashboard
Attractive cards
Professional typography
Smooth animations
Responsive desktop and mobile design
Loading indicators
Success/error notifications
Clear icons
Navigation should contain:
Dashboard | Research Assistant | Email Generator | Meeting Summarizer | Settings
Final requirement: Make the application fully interactive and functional. Do not create any authentication, login, registration, account, payment, or subscription features. Open directly to the dashboard.
